Apa itu s.id?
s.id adalah platform pengelolaan link: link pendek, bio link dan microsite, QR Code, formulir, analitik, dan AI agent AgentS dalam satu akun. Di Indonesia, s.id juga punya s.id Shop untuk jualan produk digital. Layanannya berjalan di s.id, domain .id empat karakter yang termasuk domain pemendek link terpendek di dunia.
Siapa yang membuat dan mengelola s.id?
s.id diluncurkan PANDI, pengelola domain .id, pada 2014 sebagai pemendek link. Sejak 2022 s.id dimiliki dan dikelola PT Aidi Digital Global. Fitur Microsite hadir pada 2022, s.id Shop pada 2025, dan fitur AI (AgentS, API publik, dan server MCP) pada 2026.
Bagaimana cara membuat bio link Instagram dengan s.id?
Daftar gratis di s.id, pilih 'Buat Microsite', lalu gunakan template atau mulai dari halaman kosong. Tambahkan link, foto, dan video dengan editor seret dan lepas. Setelah dipublikasikan, halaman m.id/[nama-kamu] siap dipasang di bio Instagram atau TikTok.
Apakah paket gratis s.id memiliki batas waktu?
Tidak. Paket Gratis s.id dapat digunakan tanpa batas waktu untuk membuat link pendek, halaman bio, dan QR Code sesuai kuota yang tersedia. Paket berbayar tersedia untuk domain sendiri, analitik lanjutan, kuota lebih besar, dan fitur tambahan lainnya.
Bisa dipakai buat memperpendek link WhatsApp dan Shopee?
Bisa. Tempel link WA, Shopee, Tokopedia, atau link apa pun, lalu ubah jadi m.id/custom. Link pendek lebih enak dibagikan di caption, chat, maupun bahan cetak, dan kamu tetap bisa lihat berapa orang yang klik.
QR Code s.id bisa diganti isinya setelah dicetak?
Bisa. QR Code di s.id bersifat dinamis, jadi kamu bisa ganti link tujuannya kapan saja tanpa cetak ulang. Cocok buat menu restoran, absensi kantor, atau undangan yang isinya sering berubah.
Saya bisa lihat siapa saja yang klik link saya?
Bisa. Analitik dasar untuk link, microsite, dan QR Code tersedia di paket Gratis. Kamu dapat melihat jumlah klik, lokasi umum kota/negara, perangkat (HP/Desktop), dan waktu kunjungan. Analitik lanjutan tersedia di paket berbayar.
Apa bedanya s.id dengan Linktree?
Linktree fokus di halaman link bio saja. Di s.id, link bio, pemendek link, QR Code dinamis, toko produk digital, dan formulir jadi satu paket terintegrasi. Alamat s.id juga paling pendek di dunia, hanya 4 karakter: s.id.
Bagaimana s.id melindungi data saya?
Koneksi ke s.id dilindungi dengan enkripsi SSL/TLS tingkat tinggi. Setiap tautan dipindai secara otomatis oleh SIDEX AI Security untuk mencegah phishing dan malware. Pengelolaan privasi pengguna dijamin sesuai standar regulasi Indonesia.
